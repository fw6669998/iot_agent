# IoT Agent · 物联网智能助手 使用说明

> 一个基于大语言模型的物联网平台智能助手。用自然语言对话即可完成「建产品/设备 -> 接入设备 -> 查询与控制 -> 自动化编排 -> 可视化仪表盘」的全链路操作，无需了解平台 API，也无需手写代码。

## 一、目标用户

| 用户 | 价值                                                       |
| --- |----------------------------------------------------------|
| **物联网平台运营 / 运维人员** | 不写代码、不查 API 文档，用一句话完成设备开通、属性下发、服务调用、设备接入、自动化流程设置、监控大屏开发。 |
| **应用集成开发者** | 仪表盘与自动化流程由助手生成，可直接在业务系统中复用。                              |
| **非技术终端用户** | 在企业微信等 IM 中以自然对话触发设备动作（如打印）。                             |

---

## 二、使用场景

- **办公自动化**：打印机、企业微信机器人等办公设备接入平台后，员工在企业微信中一句话即可触发打印、发送通知等动作，无需登录各设备系统，提升日常办公效率。可以一句话创建自动化工作流程,如周四用机器人在群里提醒发周报,员工离开工位忘记锁屏自动锁屏 
- **智能制造自动化**：产线传感器、执行器等设备统一接入，用自然语言查询运行状态、下发控制指令，并通过自动化流程编排设备联动，降低产线运维门槛。
- **监控运维**：运维人员用对话快速查询设备在线状态与属性、定位异常，并通过仪表盘集中监控多设备指标，故障时即时下发服务调用完成处置。
- **智慧家居**：家用电脑、手机等设备接入后，一句话完成锁屏、开启远程软件、控制闪光灯、读取电量与 WiFi，实现跨设备的统一文字/语音控制。

## 三、操作步骤

> 打开对话界面，按「创建 -> 接入 -> 查询控制 -> 自动化 -> 仪表盘 -> 端到端」的顺序，即可完成从设备开通到业务闭环的全流程。截图均位于 `doc/imgs/`。

### 步骤 1 · 创建产品和设备

用一句话创建产品、设备并定义物模型。助手会先核对是否已有同名产品，再依次完成建产品、建设备、添加属性 / 服务。

![创建产品和设备-对话](doc/imgs/对话_创建产品和设备.png)

创建完成后，在物联网平台控制台可见新增的设备：

![物联网云平台新增设备](doc/imgs/物联网云平台新增设备.png)

### 步骤 2 · 接入设备到物联网云平台

告诉助手把某台设备接入平台，助手依据该设备三元组与物模型，生成并运行设备端接入代码（属性按物模型周期上报、服务可被云平台调用），使设备真正在线。//由于该操作权限较大风险较高,公网版只输出接入代码

![接入设备到云平台-对话](doc/imgs/对话_接入设备到物联网云平台.png)

接入成功后，物联网平台开始显示设备上报的真实数据：

![接入后平台显示设备数据](doc/imgs/接入后物联网平台显示设备数据.png)

### 步骤 3 · 询问设备属性和控制设备

设备在线后，直接用自然语言查询属性或下发控制指令，助手完成属性读取、属性下发与服务调用。

![询问设备属性和控制设备](doc/imgs/询问设备属性和控制设备.png)

### 步骤 4 · 创建自动化流程

用自然语言描述联动规则，助手生成自动化流程并使其即时生效，流程内回调平台工具实现设备联动。

![创建自动化流程-对话](doc/imgs/对话_创建自动化流程.png)

生成的自动化流程：

![创建的自动化流程](doc/imgs/创建的自动化流程.png)

### 步骤 5 · 创建仪表盘

描述想要的看板，助手生成科技风 HTML 仪表盘，在仪表盘列表中即可访问，实时展示与控制设备。

![创建仪表盘-对话](doc/imgs/对话_创建仪表盘.png)

生成的仪表盘页面：

![仪表盘](doc/imgs/仪表盘.png)

### 步骤 6 · 端到端：企业微信对话触发打印

在企业微信中对话下发指令，经由平台调用「打印机」设备的打印服务，最终触发本机 PDF 打印机完成打印，验证「IM 入口 -> 平台 -> 设备动作」的完整闭环。

![企业微信对话调用文件打印](doc/imgs/企业微信对话调用文件打印.jpg)

PDF 打印机被调用：

![pdf打印机被调用](doc/imgs/pdf打印机被调用.png)
